## Данные и поведение

1. Один серверный DailyFlowView питает summary, chart, coverage, table и export. FE форматирует `delta`, `delta_percent`, coverage; не пересчитывает их и не определяет сценарий по значениям.
2. Покрытие профиля:27.07–24.10.2026 включительно, закрытые календарные дни Europe/Moscow. Default30:25.09–24.10.2026;7:18.10–24.10;90:27.07–24.10. Использовать returned `available/end_date`, не now(), Date→UTC или свежесть обычной телеметрии. Для нового профиля диапазон берётся из его ответа. Произвольный date picker в v1 не требуется.
3. Последний день — ровно `end_date`. Показать фактические поля этой даты, включая null и0. Если факт отсутствует: «За 24.10 нет факта. Предыдущий день не подставляется». Нет поиска последней непустой строки.
4. Null в числах: «—» с доступным текстом причины; null в графике: разрыв соответствующей линии.0:«0,00», точка на оси; это не пропуск и не доказательство остановки. В DTO отсутствующая запись отличается `record_state` от строки с обоими null; колонка «Состояние» это сохраняет.
5. Expected — синтетический ориентир, не ML-прогноз, норматив или подтверждённый план. Compact tag всегда виден при показе тестовых значений. Доступный диапазон и единица видны; seed/digests/version не занимают основной экран. Нет автоматической квалификации отказа по знаку дельты; дельта нейтральная ink с явным знаком.
6. Формат ru-RU, две десятичные цифры, знак у ненулевой дельты/процента. Delta units м³/сут. `delta_percent` уже число в процентных пунктах;80/100 →−20,00%, не−2000%. Expected0 даёт delta числом при известном факте, процент «—», причина «Ожидание0 · % не определён», включая both0. Нельзя показывать∞ или0% для такого случая.
7. Coverage: «Сопоставимые факт/ожидание:N изD дней» из `paired_days/calendar_days`; «Процент:N изD» из `comparable_percent_days/calendar_days`.0 входит в наличие/paired; expected0 исключает только процент. Макет:actual26, expected27, paired23, percent23 из30. Это не KPI полноты всей скважины.
8. Экспорт GET передаёт ровно displayed `start_date,end_date,dataset_version,view_id`, well ID как строка. Кнопка скачивает весь показанный период, включая прокрученные строки. Файл с тестовой маркировкой; никакого browser recalculation или отправки rows назад. Выгрузка не запускает ML. При downloading кнопка disabled со спиннером; успех объявляет «Файл скачан» только после получения файла.409 не выдаёт latest незаметно.
9. URL хранит отдельные `daily_*` параметры режима/периода; сохранить остальные query/hash и browser back/forward. На переключение well/actor/role/scope epoch/401/logout очистить daily memory и отменить read; late response не восстанавливает прежний вид. На403/404 убрать числа, provenance и export links без глобального logout.

## Доступность и движение

Порядок: существующие вкладки → режим → период → Excel → chart region → table region. Mode и period — две подписанные radio groups/segmented controls с roving tabindex и Arrow/Home/End. Выбранное состояние не только цвет: checked/pressed и видимый active fill.44px targets; перенос текста вместо обрезки.

График получает `role=img`/доступное название, единицу, диапазон и краткое описание пропусков; клавиатурный слой показывает дату и все значения/причины через ←/→, Home/End; Escape закрывает tooltip. Tooltip доступен также по tap/hover, не переносит только цветовую информацию. Если SVG не позволяет удобную навигацию, дать focusable chart region с тем же date cursor и текстовым live output; HTML-таблица остаётся полноценным эквивалентом. Tooltip не перекрывает управление периодом/экспортом. Разрывы не соединять.

Table region `tabindex=0`, доступное имя с количеством дат и инструкцией прокрутки, корректные th scope=col. Null получает доступный текст причины, «0,00» читается как ноль. Loading/export status `aria-live=polite`, ошибки/409 `role=alert`. После явного обновления фокус остаётся на инициаторе, объявляется новый период; при удалении denied subtree фокус переводится на сообщение/«К параметрам».

Reduced motion: skeleton статичны, анимация построения линий и переходов режима отключена; feedback не зависит от motion. Не добавлять фоновую анимацию или auto refresh synthetic-профиля.

- Сверить1440 и390, обе темы, семь вкладок и локальный режим; страница без horizontal overflow. Заголовки/подписи целиком видны; прокрутка только таблицы/строки вкладок.
- Проверить ordinary pair, actual0, expected0, both0, missing actual/expected/both, missing day, end_date null; summary/chart/table/XLSX соответствуют одному response. Дельты/проценты/coverage берутся с сервера.
- Проверить7/30/90, Moscow inclusive dates, точные displayed query/version/view_id при export;409 ждёт явного обновления и второго действия скачивания.
- Проверить off/error/denied/401/epoch и поздние ответы. При denied старые числа/source/links исчезают. Никаких synthetic fallback при HTTP failure.
- Клавиатура, tooltip/table equivalent, visible focus, контраст, reduced motion и скачивание проверяются на assembled isolated build. Макеты не подтверждают работоспособность React/API.
