# Тёмная тема макетов приложения

Figma: https://www.figma.com/design/km4tIbp3LnMTRrV6yi6Qho?node-id=136-285

Страница «Приложение — тёмная тема»: 58 экранов и состояний плюс палитра.
Светлые оригиналы находятся на странице «Макеты». Геометрия, тексты и
типографика сохранены; изменения касаются цветовых ролей и привязок.

В коллекции «Пульс / Токены» добавлен режим Dark. Семантические переменные
ссылаются на примитивы коллекции «Пульс / Палитра Dark». Кнопки используют
отдельные роли actionPrimary/onAccent, поля — controlBorder. Эти роли связаны
с общими компонентами; их значения Light сохраняют прежний внешний вид.

Проверка: 58/58 экранов, размеры совпадают с оригиналами, все видимые заливки
и обводки связаны с переменными, пропущенных шрифтов нет. Контраст: основной
текст 14,23:1; вторичный 7,50:1; белая подпись основной кнопки 4,55:1;
граница поля 3,68:1. Статусы тревоги, наблюдения и нормы — более 7:1.

Точные ID, палитра и результаты проверки сохранены в `figma-state.json`.
Это работа с макетами Figma; переключатель темы в React-приложении этим
изменением не добавляется.

## Переключатель темы

В 58 светлых и 58 тёмных экранах добавлена кнопка 40×40: луна в Light,
солнце в Dark. В рабочих экранах она стоит перед уведомлениями и профилем,
в экранах доступа — справа сверху. Использован существующий Button / Secondary.

В режиме Present кнопка исполняет CONDITIONAL → SET_VARIABLE_MODE для коллекции
«Пульс / Токены». Текущий экран сохраняется. Иконки связаны с режимными Boolean
переменными theme/isDark и theme/isLight. Проверены все 116 обработчиков и
границы кнопок; проверено отображение обоих цветовых режимов.

Для точного соответствия тем исходные цвета светлых экранов связаны с
семантическими переменными; отдельные исходные оттенки сохранены как Legacy-роли.
Реестр кнопок и результаты проверки находятся в figma-state.json → themeToggle.
